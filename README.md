# Personal Portfolio

## 📌 Project Description

This project is a personal portfolio website created to showcase my profile, skills, education, projects, and achievements. It provides a simple and professional way to present my technical skills and work.

## ✨ Features

- 👩‍💻 About Me section
- 🎓 Education details
- 🛠️ Technical Skills
- 💻 Projects
- 📜 Certifications
- 🏆 Achievements
- 📞 Contact Information
- 📱 Responsive design
- 🎨 Clean and user-friendly interface
